# Security Policy

Security humari sabse badi priority hai. Agar aapko SentinelEdge mein koi **vulnerability** (kami) milti hai, toh kripya use public na karein.

### Reporting a Vulnerability
Agar aapko koi security flaw dikhta hai, toh:
- Kripya humein seedha contact karein.
- Issue ka pura description aur reproduction steps provide karein.
- Vulnerability ko fix karne ke liye humein thoda time dein.

### Supported Versions
Humein humesha latest stable branch par kaam karne ki salaah di jati hai.
